# 0003 Custom Fields Without ACF

## Stato

Accettata.

## Contesto

Il progetto vieta ACF, page builder e strumenti proprietari a pagamento.

## Decisione

Creare un sistema dichiarativo interno basato su API native WordPress.

## Alternative Considerate

ACF Pro, Meta Box, Pods, clone generico di ACF.

## Conseguenze

Maggiore controllo e meno lock-in. Richiede disciplina su schema, UI, validazione e REST.
