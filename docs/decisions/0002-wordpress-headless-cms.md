# 0002 WordPress Headless CMS

## Stato

Accettata.

## Contesto

Netmarket ha familiarità con WordPress, ma il nuovo frontend deve essere statico.

## Decisione

WordPress sarà usato come CMS headless su `cms.netmarket.it`.

## Alternative Considerate

CMS SaaS, WordPress monolitico, file Markdown.

## Conseguenze

Mantiene controllo editoriale e hosting esistente, richiede API robuste e protezione del CMS.
