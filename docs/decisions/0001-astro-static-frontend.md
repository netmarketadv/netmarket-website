# 0001 Astro Static Frontend

## Stato

Accettata.

## Contesto

Serve un frontend veloce, mantenibile e statico.

## Decisione

Usare Astro con output statico e TypeScript strict.

## Alternative Considerate

Next.js SSR, WordPress tradizionale, SPA React.

## Conseguenze

Build prevedibile, JS minimo e CMS disaccoppiato. Le parti interattive useranno island dedicate.
