# Performance Budgets

Obiettivi iniziali, non garanzie:

- LCP < 1,8s al percentile 75.
- INP < 150ms.
- CLS < 0,05.
- JavaScript iniziale idealmente < 100 KB.
- Pagina standard idealmente < 1 MB.

Principi: HTML statico, JS minimo, CSS controllato, immagini dimensionate, niente hydration non necessaria.
