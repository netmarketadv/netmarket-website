# Editorial Style Guide

Date: 2026-09-02

This guide keeps Netmarket copy consistent across Astro components, CMS content and migration work.

## Voice

Netmarket should sound precise, direct and calm. The tone is premium but not cold: expert, practical, grounded in real work.

Prefer evidence over hype:

- say what Netmarket does;
- show projects, team, clients and process;
- avoid inflated claims that cannot be proven.

## Core Language

| Use | Avoid |
| --- | --- |
| `Comunichiamo valore.` | Overexplained taglines. |
| `sito web`, `siti web` | `website` in Italian public copy unless technical context requires it. |
| `ecommerce` in running text, `Ecommerce` in labels/headings | Mixing `e-commerce`, `eCommerce`, `E-Commerce` without reason. |
| `progetti` for public portfolio navigation | `case studies` as the only public label. |
| `Insight` for the editorial section | `blog` if the page is positioned as strategic content. |
| `clienti` and `progetti seguiti` | generic `brand che ci hanno scelto` if not strictly true. |
| `Parliamone.` | aggressive conversion copy. |

## Capitalization

- Navigation labels use sentence/title case naturally: `Servizi`, `Progetti`, `Insight`, `Contatti`.
- Service titles use initial capital only: `Siti web`, `Software e integrazioni`, `Branding e comunicazione`.
- Technology names keep official casing: `WordPress`, `WooCommerce`, `Shopify`, `GA4`, `Meta Ads`, `Google Ads`.

## Numbers And Dates

- Use Italian formatting in public copy: `20.000+`, `4.000+`, `5/5`.
- Do not update article dates for freshness unless content is materially revised.
- Mark old platform/news insights for editorial review when their claims can expire.

## CTA Labels

Primary:

- `Parliamone`
- `Raccontaci il progetto`
- `Prenota una chiamata`

Secondary:

- `Guarda i progetti`
- `Vai ai servizi`
- `Leggi l'insight`
- `Scopri il metodo`

Avoid many CTA variants for the same action.

## SEO And GEO Guardrails

- Do not create doorway pages or city pages without real local value.
- Do not add hidden text or invisible keyword blocks.
- JSON-LD must match visible content.
- FAQ schema should be added only when visible FAQ content and current search policy make it appropriate.
- AI visibility work means clearer entities, crawlable pages, consistent names and real proof. It is not a separate artificial content layer.
